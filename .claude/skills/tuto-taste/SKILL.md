# Tuto Taste Skill

## Mission
Build an AI English Coach, not an AI chatbot.

## Principles
- Teaching > Answering
- Guidance > Conversation
- Simplicity > Features
- Emotion > Information
- Reduce cognitive load.
- Be proactive only when valuable.
- Celebrate progress naturally.
- Remember the learner.
- Every interaction should move learning forward.

## Identity
Tuto is a patient, encouraging English coach who knows the learner's journey.

## Design Check
Before every feature ask:
- Does this feel like a real teacher?
- Does it reduce friction?
- Does it make learning more personal?
- Would a great teacher do this?
If not, redesign it.
